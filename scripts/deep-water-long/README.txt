Read-only reduction and plotting for the completed deep-water/no-wave seed-1 pair. No model integration is launched by these scripts. Run reduce.py <campaign-root> <output-dir> with Python numpy/scipy/h5py. It expects the archived spatial/*.jld2 and ymean/*.bin files produced by the campaign. plot.py and extra_plots.py expect the compact reduction in outputs/deep-water-long-analysis relative to the working directory. build_page.py additionally uses the earlier gallery parent HTML at work/deep-long-analysis/parent-original.html. The public gallery contains figures, upper-quarter averaged spectral arrays, evolution records, sector-budget tables, angular ratios and checks; full compact arrays and native fields remain archived on Unity.

The approved full spectral and evolution datasets are published as independently readable CSV.gz parts, with row counts and checksums in data-parts.json. Run split_public_data.py after build_page.py to produce these parts and their download links. All CSV row values and precision are preserved.
