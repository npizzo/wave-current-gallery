Larger-domain constant-gradient campaign, completed 4 November 2026 (US Eastern).
Six exactly 2D runs: three constant-gradient seeds and their matched no-wave controls, all to 100 Te. Parameters are in cases.json and campaign.cases. Julia 1.10.12; pinned packages in environment/. Run ring3d.jl with each campaign.cases argument list and out=<run directory>. Set ARCH=GPU for GPU execution, as specified in ring3d.jl. Analysis: python analyze.py <run directory>; ensemble.py expects data/<case name>/analysis/spectra.npz and completed.txt. Python dependencies: numpy scipy matplotlib.
Native spectra and transfer diagnostics are generated by the included simulation source. ensemble.py reproduces the time-window means; its export uses a tight bounding box to preserve the colorbar label. Full simulation data are archived on Unity, not included in this repository. The gallery includes the displayed window-mean energies as CSV and the per-run numerical checks.
